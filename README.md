# 許願神燈：願望失控 / Wish Lamp: Wishes Gone Wrong

擦一擦神燈，許三個願望。神燈會照字面意思實現，然後出事。願望發生時點點畫面上的東西，三個願望用完後，你會接任神燈。

Rub the lamp and make three wishes. The genie grants them literally, and things go wrong. Tap things on screen while a wish plays out. When the wishes run out, you become the next genie.

- 試玩 / Play: https://onholdlab.github.io/wish-lamp/
- 單一檔案 `index.html`，沒有外部程式庫。/ Single file `index.html`, no libraries.
- 匿名計數（玩完、想當燈神）送到 onholdlab 共用後端 `ohl-api`（onholdlab/ohl-api），每台裝置各只算一次；不存個人資料。/ Anonymous counts go to the shared `ohl-api` backend, once per device each; no personal data.
- 「當朋友的燈神」模式還在評估中，按鈕只收集有多少人想玩。/ The "be your friend's genie" mode is still being evaluated; the button only counts interest.
